2. Use the master prompt in 01-MASTER-PROMPT.md.

4. Keep member/admin data mocked during visual exploration.
5. Review the rendered experience before backend integration.
6. Sync/export the approved Lovable code to GitHub.
7. Integrate the approved UI into the existing ORANOS repository in a controlled development branch.

Do NOT connect Lovable directly to the production ORANOS Supabase project during visual exploration.
